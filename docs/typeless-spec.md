# Typeless 기능 명세 (2026-09-22 기준, macOS v2.8.0)

출처: typeless.com 도움말 센터(빠른 시작·문제 해결), macOS 릴리스 노트 전체(v0.1.0 2025-08 ~ v2.8.0 2026-09), 가격 페이지, 사용자 스크린샷(홈·기록·설정), 외부 리뷰.
✅ = 공식 문서로 확인 / 🔎 = 리뷰·스크린샷 기반 추정

## 1. 핵심 모드 3가지 (+ 파생 1개)

| 모드 | macOS 기본 단축키 | Windows 기본 | 동작 |
|---|---|---|---|
| 받아쓰기 (Dictate) | `Fn` | `Right Alt` | 말한 내용 → STT → AI 다듬기 → 커서 위치에 삽입 ✅ |
| 번역 (Translate) | `Fn + Left Shift` | `Right Alt + Right Shift` | 모국어로 말하면 → 대상 언어로 "현지인처럼" 번역된 글 삽입 ✅ |
| 무엇이든 물어보기 (Ask anything) | `Fn + Space` | `Right Alt + Space` | 선택 텍스트 편집/질문, 빠른 답변, 웹 작업 ✅ |
| ↳ 글쓰기 도우미 (Help me write, v2.8) | Ask anything 단축키 | 〃 | 텍스트 필드에 커서만 두고 "~하는 이메일 써줘" → 완성된 글 삽입 ✅ |

### 1-1. 녹음 제어 ✅
- **토글(핸즈프리)**: 단축키 1회 → 녹음 시작 → **메인 단축키(`Fn`) 1회**로 종료. 번역·Ask도 종료는 항상 `Fn`.
- 원래는 누르고 있는 동안만 녹음(push-to-talk)이었고 v1.2.0에서 핸즈프리 추가 → 둘 다 지원.
- 시작 시 **상호작용 사운드** + 화면 하단 **음성 바(Voice bar)** 표시. 누르는 순간 마이크 즉시 활성화(v0.4.4).
- **1회 최대 9분**. 8분에 음성 바에서 60초 카운트다운 → 한도 도달 시 그때까지 내용을 자동으로 기록에 저장.
- 처리 중 진행률 표시(v0.4.3).

### 1-2. 받아쓰기 — AI 다듬기 규칙 ✅
- 필러 제거(음/어/um/uh/you know), 반복 제거
- **자기 정정 반영**: 말하다 바꾼 건 최종 결정만 남김 ("3시, 아니 4시" → "4시")
- **자동 서식**: 나열·단계·요점 → 리스트/구조화 문단
- 순서 없이 말해도 중요도 순으로 재구성(v2.0), 부연 설명은 본문이 아니라 "맥락"으로만 사용(v2.0)
- 기억 안 나는 이름을 설명하면 지어내지 않고 정확한 이름으로 채움(v2.0)
- 단어 선택 개선, 톤 유지, 결과물은 "직접 타이핑한 것처럼"
- 100+ 언어 자동 감지, 한 문장 안에서 언어 섞어 말하기 가능
- 언어 변형(영/중/스/프/포 지역 방언) 선택
- 🔎 사용자 실제 출력 예: `STT(음성인식)`, `가벼운(lightweight)`, 번호 목록을 문단 안에 `1. … 2. …`로 인라인 배치

### 1-3. 앱별 톤 ✅/🔎
- "앱마다 다른 톤": 이메일(Gmail/Outlook)=격식, 채팅(Slack/카톡/iMessage)=캐주얼, 코드 에디터/터미널/AI 프롬프트=구조적·간결
- 70+ 앱 명시 지원(Office, Google Docs, Notion, Slack, ChatGPT, Claude, VS Code, Terminal 등)

### 1-4. 번역 ✅
- 설정에서 **대상 언어 여러 개**를 미리 등록하고 드래그로 우선순위 정렬 (스크린샷: 번역 대상 = 영어(캐나다))
- 녹음 중 음성 바 위 언어 표시에 마우스를 올려 대상 언어 즉시 전환
- 단순 직역이 아니라 목적(메시지/이메일/게시물)에 맞게 다듬고 화자의 에너지·톤 유지(v1.8)

### 1-5. 무엇이든 물어보기 ✅
| 상황 | 결과 |
|---|---|
| 편집 가능한 텍스트 선택 + "더 짧게/정중하게/표로" | **선택 영역을 즉시 교체** |
| 읽기 전용 텍스트 선택(웹·PDF) + "요약/설명/번역해줘" | 원문은 그대로, **팝업 카드**에 답변 |
| 선택 없음 + 텍스트 필드 포커스 + "~ 써줘" | Help me write → 필드에 삽입 |
| 선택 없음 + 질문 | 필요 시 **웹 검색** 후 팝업 카드(마크다운 렌더) |
| 선택 없음 + "~ 영상/제품/근처 장소 찾아줘" | 관련 웹페이지를 검색된 상태로 **열어줌** |

## 2. 부가 기능

### 2-1. 사전 (Dictionary) ✅
- 사람 이름·약어·도메인 용어 수동 추가, **CSV 대량 가져오기**, 검색, 편집/삭제, 다중 선택 삭제(v2.6)
- **자동 추가**: 받아쓰기 후 사용자가 단어를 고치면 선호 철자를 학습해 "자동 추가됨"에 등록
- 필터: 전체 / 자동 추가됨 / 수동 추가됨, 캡슐(칩) 그리드 UI

### 2-2. 기록 (History) ✅
- 받아쓰기 + Ask 결과를 **기기 로컬**에 저장. 필터: 모두 / 받아쓰기 / 무엇이든 물어보세요, 날짜별 그룹(오늘…)
- 항목별: 복사, 피드백, **재시도(같은 오디오로 재처리)**, 오디오 다운로드, 삭제 / 전체 삭제
- 보관 기간: 영원히 · 1년 · 1개월 · 1주 · 24시간 · 안 함
- 클라우드 동기화 토글 + 클라우드 보관 기간(v2.4, Pro)
- 텍스트 필드가 없거나 카드를 닫아서 놓친 결과는 기록에서 복구

### 2-3. 개인화 ✅
- 사용할수록 격식/캐주얼, 간결/상세 등 **스타일 패턴**만 추상적으로 학습(내용은 저장 안 한다고 주장)
- 홈의 개인화 진행도 카드 + "보고서 보기", 설정에서 끄기 가능

### 2-4. 홈 인사이트 ✅ (스크린샷)
- 받아쓴 단어 수, 절약된 시간, 평균 WPM, 총 받아쓰기 시간
- 활동 일수, 현재 연속 일수, 최장 연속 일수, 요일×주 **히트맵**(GitHub 잔디 형태, 4단계 농도)
- 공유 카드 생성(v2.5), 우측에 단축키 요약

### 2-5. 설정 ✅
- **계정 / 설정 / 개인화 / 정보 / 도움말** 탭
- 단축키: 기능별 변경 + "추가하기"로 여러 개(외부 키보드, **마우스 사이드/가운데 버튼**(v2.7)), 텍스트 필드에서 테스트
- 오디오: 마이크(자동 감지/특정 장치, 레벨 미터), 상호작용 사운드, **받아쓰기 중 다른 오디오 음소거**
- 언어: 인터페이스 언어(58개), 번역 대상(복수), 언어 변형
- 일반: 모양(라이트/다크/시스템), 로그인 시 실행, Dock에 표시
- 권한: 손쉬운 사용(텍스트 삽입·Fn 감지), 마이크. Fn이 이모지/받아쓰기와 충돌 시 시스템 설정에서 해제 안내

### 2-6. 기타
- 속삭임 모드(Whisper mode): 작게 말해도 인식 🔎(가격표에만 기재)
- 플랫폼: macOS, Windows, iOS, Android(모바일은 **Typeless 키보드**의 Speak 버튼 방식, "말해서 편집" 모바일 전용)
- 요금: Free 주 8,000→2,000단어(2026-09-22~), Pro $12/월(연) · $30/월, 무제한 + 향상된 정확도
- 오프라인 불가(클라우드 전용), 오디오는 서버로 전송 후 무보존 주장

## 3. 우리 앱(Sori) 매핑 — ElevenLabs + OpenRouter

| Typeless | Sori 구현 |
|---|---|
| STT | ElevenLabs `scribe_v2` (batch, `keyterms`로 사전 반영) — 필요 시 Scribe v2 Realtime(WebSocket)로 말하는 동안 전사 |
| AI 다듬기/번역/Ask | OpenRouter Chat Completions, 빠른 모델 기본 + 설정에서 변경 |
| 앱별 톤 | 최상단 앱 번들 ID → 카테고리(이메일/채팅/코드/AI/문서) → 프롬프트 스타일 |
| 사전 | STT keyterms + LLM 프롬프트의 "선호 표기" 목록, CSV 가져오기 |
| 기록 | 로컬 SQLite + 오디오 파일, 보관 기간, 재시도 |
| 웹 검색 | OpenRouter web 플러그인(`:online`) |
| 개인화·클라우드 동기화·팀/요금제 | 개인용이라 제외(추후) |
